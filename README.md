# TCF Oral C1 App

This package contains the mobile-friendly TCF Oral C1 memorization app and local mp3 audio.

Open `index.html` on a computer, or upload this folder to any static hosting service such as Netlify, Vercel, Cloudflare Pages, or GitHub Pages.

For phones, hosting is recommended. After opening the hosted URL in Chrome or Safari, use "Add to Home Screen" to install it like an app.

Private files such as `tts_config.json`, original PDFs, and API keys are not included.
